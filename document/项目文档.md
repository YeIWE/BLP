# BLP 电商系统 — 项目文档

> 版本: 2.0 | 更新: 2026-05-19 | Phase 1/2/3 完成

## 一、项目概述

BLP 大型学习型电商系统，前后端分离 + 微服务架构，覆盖 10 个中间件、14 个微服务。

**GitHub:** https://github.com/YeIWE/BLP

## 三、微服务架构 (14 个)

```
Gateway (:18000) → Nacos (:8848)
  ├── auth-svc      (:18080) — JWT 签发 + RBAC
  ├── user-svc      (:9002)  — 用户/角色/菜单 CRUD
  ├── product-svc   (:9003)  — 商品/分类/品牌 + MinIO
  ├── cart-svc      (:9005)  — Redis 购物车
  ├── order-svc     (:9004)  — 订单 + RabbitMQ
  ├── payment-svc   (:9006)  — 模拟支付 + RabbitMQ
  ├── inventory-svc (:9007)  — Redis Lua 库存
  ├── file-svc      (:9012)  — MinIO 通用上传
  ├── promotion-svc (:9008)  — 秒杀 + Redis + RabbitMQ
  ├── review-svc    (:9009)  — 商品评价
  ├── search-svc    (:9010)  — Elasticsearch 搜索
  ├── log-svc       (:9011)  — Kafka 消费 + MongoDB
  └── dashboard-svc (:9013)  — WebSocket 实时大屏
```
