# BLP 电商系统 — 项目文档

> 版本: 1.0 | 更新: 2026-05-18 | Phase 1

## 一、项目概述

BLP 是一个大型学习型电商系统，采用前后端分离 + 微服务架构。目标是完整覆盖后端核心知识体系中所有中间件和技术栈（除 K8s）。

**GitHub:** https://github.com/YeIWE/BLP

## 三、微服务架构

```
客户端浏览器
  ├── 管理后台 (:9528)  Vue3 + Element Plus
  ├── 用户前台 (:9527)  Vue3 + Element Plus
  │
  ▼
Gateway (:18000) — JWT 校验 + 路由分发
  │
  ▼
Nacos (:8848) — 服务注册 · 配置中心 (暂禁用)

  ├── auth-svc (:18080) — 认证授权 / JWT 签发 / RBAC
  ├── user-svc (:9002)  — 用户/角色/菜单 CRUD
  ├── product-svc (:9003) — 商品/分类/品牌 + MinIO
  ├── cart-svc     (P2) — 购物车
  ├── order-svc    (P2) — 订单
  ├── payment-svc  (P2) — 支付
  ├── inventory-svc(P2) — 库存
  ├── file-svc     (P2) — 文件管理
  ├── promotion-svc(P3) — 秒杀/优惠券
  ├── review-svc   (P3) — 评价
  ├── search-svc   (P3) — 搜索(ES)
  ├── log-svc      (P3) — 日志(Kafka)
  └── dashboard-svc(P3) — 数据大屏
```
