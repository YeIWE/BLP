# BLP 电商系统 — 用户手册

> 版本: 1.0 | 更新: 2026-05-18

## 一、管理后台 (blp-admin)

**地址:** http://localhost:9528

### 1.1 登录

1. 打开浏览器访问 http://localhost:9528
2. 输入用户名: `admin`
3. 输入密码: `admin123`
4. 点击「登录」

### 1.2 功能导航

登录后左侧菜单根据角色权限动态加载:
- **控制台** — 系统概览 (用户数/商品数/订单数)
- **系统管理**
  - 用户管理 — 用户的增删改查
  - 角色管理 — 角色的增删改查
  - 菜单管理 — 菜单树的管理 (目录/菜单/按钮)
- **商品管理**
  - 商品列表 — 商品的增删改查 + 图片上传
  - 分类管理 — 商品分类树的管理
  - 品牌管理 — 品牌的增删改查 + Logo上传

### 1.3 主题切换

顶部导航栏右侧有5个色点:
- 蓝色 (默认)
- 黄色
- 粉色
- 绿色
- 紫色

点击色点即可切换主题，主题偏好保存在浏览器 localStorage。

### 1.4 语言切换

顶部导航栏右侧「语言」下拉菜单，支持:
- 中文 (默认)
- English
- 日本語
- 한국어
- Deutsch

选择后即时切换，语言偏好保存在浏览器 localStorage。

## 二、用户前台 (blp-web)

**地址:** http://localhost:9527

### 2.1 首页

- 顶部轮播Banner
- 分类导航区 (6个分类卡片)
- 热门推荐商品
- 搜索栏 (跳转商品搜索页)

### 2.2 商品搜索

- 左侧分类筛选
- 搜索框输入关键词
- 商品卡片网格展示
- 分页浏览

### 2.3 商品详情

- 商品大图展示
- 价格、库存信息
- 商品描述
- 加入购物车按钮 (Phase 2 可用)

### 2.4 主题与语言

同管理后台，顶部导航栏支持5种主题配色和5种语言切换。

## 三、API 文档 (Swagger)

每个后端服务都集成了 Knife4j (Swagger UI):

- **auth-svc:** http://localhost:18080/doc.html
- **user-svc:** http://localhost:9002/doc.html
- **product-svc:** http://localhost:9003/doc.html

可在线查看和测试所有 REST API 接口。

## 四、开发建议

1. **先启动中间件** → **再启动后端** → **最后启动前端**
2. 后端修改后执行 `mvn compile` 刷新
3. 前端支持热更新 (HMR)，修改后自动刷新
4. 管理后台登录后会调用 `/user/menu/user/1` 获取菜单 (userId=1 为admin)
