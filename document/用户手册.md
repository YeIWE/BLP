# BLP 电商系统 — 用户手册

> 版本: 2.0 | 更新: 2026-05-19

## 一、管理后台 (http://localhost:9528)

**登录:** admin / admin123

### 页面导航

| 一级菜单 | 二级页面 | 功能 |
|---------|---------|------|
| 控制台 | 首页 | 今日订单/营收/商品/用户 4 项实时统计 |
| 系统管理 | 用户管理 | 用户 CRUD + 搜索 + 分页 |
| | 角色管理 | 角色 CRUD |
| | 菜单管理 | 菜单树 (目录/菜单/按钮) |
| 商品管理 | 商品列表 | 商品 CRUD + 图片上传(MinIO) |
| | 分类管理 | 分类树管理 |
| | 品牌管理 | 品牌 CRUD + Logo上传 |
| 订单管理 | 订单列表 | 订单查询 + 发货/完成状态操作 |
| 营销管理 | 秒杀管理 | 秒杀活动 CRUD |

### 主题与语言
- **5 种主题:** 顶部右侧色点切换 (蓝/黄/粉/绿/紫)
- **5 种语言:** 顶部右侧下拉切换 (中文/English/日本語/한국어/Deutsch)

## 二、用户前台 (http://localhost:9527)

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | / | Banner + 分类导航 + 推荐商品 |
| 搜索 | /product | 分类筛选 + 关键词搜索 + 商品列表 |
| 详情 | /product/:id | 商品大图 + 价格 + 评价列表 |
| 购物车 | /cart | 商品管理 + 数量修改 + 选择结算 |
| 结算 | /checkout | 收货信息 + 订单确认 + 提交 |
| 支付 | /payment/:orderId | 支付宝/微信模拟支付 |
| 我的订单 | /orders | 订单列表 + 状态跟踪 |
| 秒杀 | /seckill | 秒杀商品 + 倒计时 + 抢购 |
