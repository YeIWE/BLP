# BLP 电商系统 — 技术文档

> 版本: 2.0 | 更新: 2026-05-19

## 一、项目结构

```
BLP/
├── blp-parent/          # Maven 父 POM
├── blp-common/          # ApiResult / PageResult / BizException / AuthConstant
├── blp-gateway/         # :18000  Spring Cloud Gateway + JWT 全局校验
├── blp-auth/            # :18080  JWT 签发 + RBAC + Spring Security
├── blp-user/            # :9002   用户/角色/菜单 CRUD
├── blp-product/         # :9003   商品/分类/品牌 + MinIO 上传
├── blp-cart/            # :9005   Redis Hash 购物车
├── blp-order/           # :9004   订单 + RabbitMQ order.events
├── blp-payment/         # :9006   模拟支付 + RabbitMQ PAYMENT_SUCCESS
├── blp-inventory/       # :9007   Redis Lua 原子库存扣减
├── blp-file/            # :9012   MinIO 通用文件管理
├── blp-promotion/       # :9008   秒杀 Redis+Lua + RabbitMQ seckill.orders
├── blp-review/          # :9009   商品评价 + 评分统计
├── blp-search/          # :9010   Elasticsearch 全文搜索
├── blp-log/             # :9011   Kafka blp-logs → MongoDB user_logs
├── blp-dashboard/       # :9013   WebSocket /ws/dashboard 实时推送
├── blp-admin/           # :9528   管理后台 Vue3 SPA
├── blp-web/             # :9527   用户前台 Vue3 SPA
├── docs/sql/            # 数据库迁移脚本 (V1/V2/V3)
├── document/            # 企业级文档
├── reso/                # 中间件挂载数据 + middleware-config.yml
└── 项目文档/             # 原始需求文档
```

## 二、数据库 (13 张表)

**RBAC:** sys_user, sys_role, sys_menu, sys_user_role, sys_role_menu
**商品域:** pms_category, pms_brand, pms_product
**交易域:** oms_order, oms_order_item, pay_payment
**营销域:** prom_seckill, prom_coupon, pms_review

## 三、RabbitMQ 消息流

```
order-svc ──→ order.events ──→ (order created/status changed)
payment-svc ──→ PAYMENT_SUCCESS ──→ order-svc (update status to PAID)
promotion-svc ──→ seckill.orders ──→ (seckill order processing)
```

## 四、Kafka 消息流

```
blp-web (前端埋点) ──→ blp-logs topic ──→ log-svc ──→ MongoDB user_logs
```

## 五、Redis 数据结构

| Key | 类型 | 用途 |
|-----|------|------|
| cart:user:{userId} | Hash | 购物车 (productId → JSON) |
| seckill:stock:{id} | String | 秒杀库存预热 |
| inventory:{productId} | String | 库存缓存 |

## 六、安全

- Spring Security 6.2 → `SessionCreationPolicy.STATELESS`
- JWT 认证: 自定义 `/auth/login` + RSA 签名
- Gateway: `AuthGlobalFilter` 校验 Bearer token
- 白名单路径: `/auth/login`, `/auth/oauth2/jwks`, `/v3/api-docs/**`, `/swagger-ui/**`, `/doc.html`, `/webjars/**`
