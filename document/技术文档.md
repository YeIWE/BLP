## 二、后端架构

### 2.1 认证流程

```
POST /auth/login {"username":"admin","password":"admin123"}
  → TokenController.login()
    → AuthenticationManager.authenticate()
      → UserDetailsServiceImpl.loadUserByUsername()
        → UserMapper.selectByUsername()  [MySQL: sys_user]
        → UserMapper.selectRolesByUserId()  [MySQL: sys_role]
        → UserMapper.selectPermissionsByUserId()  [MySQL: sys_menu]
    → 生成 RSA-signed JWT (RS256)
  ← {"code":200, "data":{"access_token":"eyJ...", "refresh_token":"eyJ..."}}
```

### 2.2 JWT 结构

```json
{
  "sub": "admin",
  "iss": "blp-auth",
  "iat": 1680000000,
  "exp": 1680001800,
  "jti": "uuid",
  "authorities": ["ROLE_ADMIN", "sys:user:list", "sys:user:query", ...]
}
```

### 2.3 安全配置

- Spring Security 6.2.4
- 无状态会话 (SessionCreationPolicy.STATELESS)
- CSRF 禁用 (REST API)
- `/auth/**` 路径公开访问
- 其他请求需认证 (permitAll for now during dev)
- BCrypt 密码编码

### 2.4 数据库设计 (Phase 1)

**RBAC 5表:**
- `sys_user` — 用户 (admin / BCrypt)
- `sys_role` — 角色 (ADMIN, USER)
- `sys_menu` — 菜单 (目录/菜单/按钮)
- `sys_user_role` — 用户-角色关联
- `sys_role_menu` — 角色-菜单关联

**商品域 3表:**
- `pms_category` — 分类 (树形, id + parent_id)
- `pms_brand` — 品牌
- `pms_product` — 商品 (含图片/价格/库存)
