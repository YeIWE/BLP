# BLP 电商系统 — 操作文档

> 版本: 2.0 | 更新: 2026-05-19

## 一、中间件启动

```bash
# 确保 Docker Desktop 运行中

# MySQL (已运行)
docker run -d --name mysql-server -p 3307:3306 -e MYSQL_ROOT_PASSWORD=root mysql:8.4

# Redis (已运行, requirepass)
docker run -d --name redis-server -p 6379:6379 redis:7.4 redis-server --requirepass redis

# Nacos (已运行, 无认证)
docker run -d --name nacos-server -p 8848:8848 -p 9848:9848 \
  -e MODE=standalone \
  -e NACOS_AUTH_ENABLE=false \
  -e NACOS_AUTH_IDENTITY_KEY=serverIdentity \
  -e NACOS_AUTH_IDENTITY_VALUE=security \
  -e NACOS_AUTH_TOKEN=U2VjcmV0S2V5MDEyMzQ1Njc4OTAxMjM0NTY3ODkwMTIzNDU2Nzg5MDEyMzQ1Njc4OTAxMjM0NTY3ODkwMTIzNA== \
  nacos/nacos-server:latest

# MinIO
docker run -d --name minio-server -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=minioadmin -e MINIO_ROOT_PASSWORD=minioadmin \
  minio/minio server /data --console-address ":9001"

# RabbitMQ
docker run -d --name rabbitmq-server -p 5672:5672 -p 15672:15672 \
  -e RABBITMQ_DEFAULT_USER=rabbitmq -e RABBITMQ_DEFAULT_PASS=rabbitmq \
  rabbitmq:4.0-management

# Kafka
docker run -d --name kafka-server -p 9092:9092 apache/kafka:latest

# Elasticsearch
docker run -d --name es-server -p 9200:9200 -p 9300:9300 \
  -e "discovery.type=single-node" -e "xpack.security.enabled=false" \
  -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" elasticsearch:8.15.0

# MongoDB
docker run -d --name mongo-server -p 27017:27017 mongo:7

# Nginx
docker run -d --name nginx-server -p 8080:80 nginx:latest
```

## 二、数据库初始化

```bash
# Phase 1 表 (RBAC + 商品)
docker exec -i mysql-server mysql -uroot -proot < docs/sql/V1__init_rbac.sql

# Phase 2 表 (订单 + 支付)
docker exec -i mysql-server mysql -uroot -proot < docs/sql/V2__phase2_tables.sql

# Phase 3 表 (秒杀 + 优惠券 + 评价)
docker exec -i mysql-server mysql -uroot -proot < docs/sql/V3__phase3_tables.sql

# 验证
docker exec mysql-server mysql -uroot -proot -e "USE blp_db; SHOW TABLES;"
```

## 三、后端编译与启动

```bash

cd blp-parent && mvn clean compile

# 按顺序启动 (各终端)
cd blp-auth      && mvn spring-boot:run   # :18080
cd blp-user      && mvn spring-boot:run   # :9002
cd blp-product   && mvn spring-boot:run   # :9003
```

## 五、验证清单

```bash
# 认证
curl -X POST http://localhost:18080/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 用户列表 (需 Bearer token)
curl http://localhost:18080/user/page?page=1

# 商品搜索
curl http://localhost:18080/product/page?keyword=test

# 中间件状态
curl http://localhost:8848/nacos/v1/ns/operator/metrics
curl http://localhost:9000/minio/health/live
curl http://localhost:9200
curl -u rabbitmq:rabbitmq http://localhost:15672/api/overview
```

## 六、故障排查

| 问题 | 原因 | 解决 |
|------|------|------|
| Port 18080 already in use | 旧 Java 进程 | `taskkill //F //IM java.exe` |
| MySQL Communications link failure | 端口不对或容器停 | 确认 3307: `netstat -ano \| grep 3307` |
| Nacos gRPC 401 | 认证未关闭 | 检查容器环境变量 |
| Kafka/RabbitMQ 不响应 | 容器可能重启 | `docker ps`, 等待 30s 就绪 |
| 编译错误 | 依赖不完整 | `cd blp-parent && mvn clean install -DskipTests` |
