# BLP 电商系统 — 操作文档

> 版本: 1.0 | 更新: 2026-05-18

## 一、环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | Azul Zulu 17.0.18 |
| Maven | 3.6+ | 构建工具 |
| Node.js | 20+ | 前端构建 |
| Docker Desktop | 29+ | 中间件容器 |
| Git | 2.x | 版本管理 |

## 二、中间件启动

### 2.1 启动所有中间件

```bash
# 确保 Docker Desktop 正在运行

# 启动 MySQL
docker run -d --name mysql-server -p 3307:3306 -e MYSQL_ROOT_PASSWORD=root mysql:8.4

# 启动 Redis
docker run -d --name redis-server -p 6379:6379 redis:7.4 redis-server --requirepass redis --appendonly yes

# 启动 Nacos
docker run -d --name nacos-server -p 8848:8848 -p 9848:9848 -e MODE=standalone nacos/nacos-server:latest

# 启动 MinIO
docker run -d --name minio-server -p 9000:9000 -p 9001:9001 -e MINIO_ROOT_USER=minioadmin -e MINIO_ROOT_PASSWORD=minioadmin minio/minio server /data --console-address ":9001"

# 启动 RabbitMQ
docker run -d --name rabbitmq-server -p 5672:5672 -p 15672:15672 -e RABBITMQ_DEFAULT_USER=rabbitmq -e RABBITMQ_DEFAULT_PASS=rabbitmq rabbitmq:4.0-management

# 启动 Kafka
docker run -d --name kafka-server -p 9092:9092 apache/kafka:latest

# 启动 Elasticsearch
docker run -d --name es-server -p 9200:9200 -p 9300:9300 -e "discovery.type=single-node" -e "xpack.security.enabled=false" -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" elasticsearch:8.15.0

# 启动 MongoDB
docker run -d --name mongo-server -p 27017:27017 mongo:7
```

### 2.2 初始化数据库

```bash
# 等待 MySQL 就绪后执行
docker exec -i mysql-server mysql -uroot -proot < docs/sql/V1__init_rbac.sql

# 验证
docker exec mysql-server mysql -uroot -proot -e "USE blp_db; SHOW TABLES;"
```

## 三、后端启动

### 3.1 编译

```bash
cd blp-parent
mvn clean compile
```

### 3.2 启动顺序

```bash
# 1. Auth Service (先启动，其他服务可能依赖)
cd blp-auth
mvn spring-boot:run

# 2. User Service
cd blp-user
mvn spring-boot:run

# 3. Product Service
cd blp-product
mvn spring-boot:run

# 4. Gateway (最后启动)
cd blp-gateway
mvn spring-boot:run
```

### 3.3 验证

```bash
# 测试认证
curl -X POST http://localhost:18080/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 预期返回: {"code":200,"data":{"access_token":"eyJ...",...}}
```

## 四、前端启动

```bash
# 管理后台
cd blp-admin
npm install
npm run dev        # → http://localhost:9528

# 用户前台
cd blp-web
npm install
npm run dev        # → http://localhost:9527
```

## 五、常用命令

```bash
# 查看所有运行中的容器
docker ps

# 查看容器日志
docker logs -f mysql-server

# 停止所有容器
docker stop $(docker ps -q)

# 清理编译产物
mvn clean
```

## 六、故障排查

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| MySQL 连接失败 | 容器未启动或端口错误 | 确认端口3307, `docker ps` |
| 端口冲突 | 旧进程占用 | `netstat -ano \| grep <port>` 然后 `taskkill //F //PID <pid>` |
| Nacos gRPC 401 | Nacos认证未配置 | 在 application.yml 添加 username/password |
| MinIO上传失败 | endpoint端口错误 | API端口是9000,不是9001 |
