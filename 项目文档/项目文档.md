# BLP 电商系统 — 项目需求文档

> 最后更新：2026-05-18

## 一、项目概述

构建一个完整的电商系统，涵盖前后端分离 + 微服务架构，集成 13 个中间件和 13 个微服务，按三阶段实施。

## 四、技术架构设计

### 4.1 整体架构

```
客户端浏览器
     ├── 管理后台 (:9528)  Vue3 + Element Plus
     ├── 用户前台 (:9527)  Vue3 + Element Plus
     │
     ▼
Gateway (:9000) — JWT 全局校验 + 路由分发
     │
     ▼
Nacos (:8848) — 服务注册 · 配置中心
Sentinel (:8719) — 熔断降级 · 限流
     │
     ├─ auth-svc (:9001) ─── Redis (令牌)
     ├─ user-svc (:9002) ─── MySQL
     ├─ product-svc (:9003) ─── MySQL + MinIO + ES(P2) + MongoDB(P3)
     ├─ cart-svc (:9005) ─── Redis
     ├─ order-svc (:9004) ─── MySQL + RabbitMQ + Kafka(P3)
     ├─ payment-svc (:9006) ─── RabbitMQ + 支付宝/微信沙箱
     ├─ inventory-svc (:9007) ─── Redis + MySQL
     ├─ file-svc (:9012) ─── MinIO
     ├─ promotion-svc (:9008) ─── Redis + RabbitMQ
     ├─ review-svc (:9009) ─── MySQL + Redis
     ├─ search-svc (:9010) ─── Elasticsearch
     ├─ log-svc (:9011) ─── Kafka + MongoDB
     └─ dashboard-svc (:9013) ─── Redis + WebSocket
```

### 4.2 安全体系

- OAuth2 密码模式（password grant_type）→ 后续扩展短信/社交登录
- JWT 无状态 Token（Access Token 30min + Refresh Token 7d）
- RBAC 五张表模型（user / role / menu / user_role / role_menu）
- Gateway 全局 JWT 校验 + 微服务层 `@PreAuthorize` 注解校验
- 前端动态菜单 = 后端返回用户可访问的菜单树
- 前端路由守卫 + 后端接口权限双重校验

## 七、约束与规范

1. **所有中间件本地部署**：默认端口、无密码（Redis 6379、MySQL 3306 等）
2. **中间件先单机后集群**：Phase 1-2 单机，Phase 3 按需扩展
3. **每次更新产出三类文档**：软件架构文档、技术文档、用户手册（配页面截图）
4. **前端脚手架创建**：`npm create vite@latest`（Vue 3 + TS）
5. **后端脚手架创建**：Spring Initializr（Maven + Java 17 + Spring Boot 3.2）
6. **MySQL 优化声明**：索引设计、慢查询日志、连接池配置随 Phase 文档说明
7. **测试案例**：每个服务独立提供功能测试
8. **达梦/Oracle**：仅学习参考，不在系统中使用
